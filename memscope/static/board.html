memlayer · what we're building

A shared memory for every AI tool in your company.

Plug it in once. Every AI tool reads and writes from the same place — without leaking what shouldn't be shared.

Today, every AI tool in your company starts from zero. They don't share knowledge. They redo each other's work. They leak data they shouldn't.

What we're building is the one trustworthy memory underneath all of them — connecting a new AI tool means it instantly knows your company, and only sees what it's allowed to see.

What's already built

Foundations. Each one is a real promise the system can keep right now — you can demo any of them on a laptop today.

The foundation

Write things down. They stay written.

Every AI tool, every human, every connector can drop facts into one shared place — and nothing ever quietly disappears.

Cost

Don't pay twice for the same thing.

If two tools both notice the same paragraph, we only process it once. Re-ingest the same doc = zero new cost.

Trust

Permissions you can't leak around.

The "who's allowed to see this?" check happens deep in the database, before any search results are ranked. Forbidden content is never returned — not even by accident.

Conflict

Humans always win arguments with AI.

When an AI guesses wrong and a human corrects it, the system literally cannot let a later AI guess overwrite the correction.

Search

Find the right info even when the words don't match.

Search by meaning and by exact words at the same time, fused together — so you don't miss the right answer just because someone phrased it differently.

Memory care

Old wrong guesses forget themselves.

A confident statement that nobody confirms slowly fades. A statement that gets reinforced stays sharp. The system manages its own attic.

Safety

Strip secrets at the door.

If a Slack thread accidentally contains an API key or password, we never store it. Prevent leaks at ingest — much cheaper than cleanup.

Open standard

Any AI tool plugs in via one protocol.

Claude Code, Cursor, any MCP-speaking client can read and write to our memory through a standard interface.

See it work

A web dashboard to see it all.

Landing page, three demo scenarios, three inspector views, a 2-slide deck — all at one URL. Anyone can play with it without a tutorial.

Battle-tested

We attacked our own system and patched the holes.

Ran a full security audit, found 3 critical and 5 high-severity bugs, fixed all of them. The substrate's trust promises hold up.

★ The moat

What makes us hard to copy

Four genuinely hard problems nobody has solved together. This is what we said in the pitch we're raising to build. Each one is a separate research project. The order below is the order we'd tackle them.

#1 · After auth

Know that "Ali in Slack" and "ali@acme.com" are the same person.

And don't get it wrong — because a bad guess unlocks one person's restricted content to a stranger. We'll build this with confidence scores and human review for risky merges.

#3 · Builds on #1

When two humans disagree, model who has the right to override whom.

Today "human beats AI" is enough. Tomorrow: a security lead's "this is wrong" overrides an engineer's "this is right" — but only for security-shaped facts. Real governance.

#2

Turn 1,000 messages into 1 honest summary — with receipts.

Every claim in the summary traceable back to a specific source. A future correction updates only the affected evidence. The hard part: don't make things up.

#4 · Deepest

Learn from every company's data — without any of them seeing each other's.

The platform gets smarter from every workspace, but no workspace's content ever bleeds into another. Federated learning with mathematical privacy guarantees.
